# web-de-omega-proyecto


Ciberseguridad con criterio, ética y transparencia:

Omega es un proyecto web que presenta un servicio de ciberseguridad pensado para ayudar a las organizaciones a conocer sus riesgos, fortalecer sus defensas y responder con confianza ante los incidentes. Este repositorio contiene el sitio institucional, desarrollado en HTML y CSS.

Sobre el proyecto:

La seguridad de la información no consiste solo en tecnología: depende de las personas, de los procesos y de la confianza entre quien protege y quien es protegido. Con esa idea nace Omega, y el sitio busca reflejarla en cada sección: explicar con claridad cómo trabajamos, qué ofrecemos y cómo puedes ponerte en contacto con nosotros.

Nuestra forma de trabajar.

Cada servicio se apoya en principios que guían todo el proceso:

Auditorías: analizamos la postura de seguridad de tu organización para identificar dónde estás hoy y qué se puede mejorar.
Pruebas de seguridad: realizamos evaluaciones técnicas controladas para detectar vulnerabilidades antes de que lo haga un atacante.
Informes claros: presentamos los hallazgos en un lenguaje comprensible, con recomendaciones concretas y priorizadas.
Respuesta a incidentes: acompañamos a los equipos cuando ocurre un problema, con un plan de acción ordenado.
Capacitación: formamos a las personas, porque un equipo informado es la primera línea de defensa.
Autorización previa: solo trabajamos con el permiso expreso del cliente y dentro de un alcance acordado.
Confidencialidad: tratamos la información de cada cliente con la máxima reserva.

Cómo ejecutarlo

El sitio es estático, por lo que no necesita instalación ni dependencias.

Clona el repositorio:
bash
   git clone https://github.com/kevin7779/kevin7779-Omega.git
   cd kevin7779-Omega
   
Abre index.html directamente en tu navegador, o, si prefieres un servidor local:
bash
   python -m http.server 8000

Luego visita http://localhost:8000.
